# Pastelaria de Arquivos

Conversor de arquivos para Windows: PDF, Word, Excel, imagem, vídeo e áudio. Arraste o arquivo no Explorer e aperte **Shift** para abrir a roda de ações, ou use a janela do app. Tudo roda no seu computador.

## Instalar

Baixe o instalador na página de [Releases](../../releases/latest) (`Pastelaria-de-Arquivos-Setup.exe`) e execute. Não precisa de administrador. O Windows pode mostrar o aviso do SmartScreen porque o instalador não é assinado: clique em *Mais informações* e *Executar assim mesmo*.

## Atualizar

O app avisa quando há versão nova. É só clicar em **Atualizar agora**.
